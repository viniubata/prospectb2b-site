# prospectb2b-site

Site institucional do ProspectB2B PRO (https://prospectb2b-pro.vercel.app/).

Arquivos estáticos: `index.html`, `styles.css`, `app.js`, `config.js`, `fonts/`, `robots.txt`, `sitemap.xml`.
Imagens e vídeo ficam no CDN `viniubata/prospectb2b-assets`, referenciados por SHA de commit.

Publicação: push em `main` → deploy na Vercel (projeto `prospectb2b-pro`).
Configuração de medição (Meta Pixel / GA4) em `config.js`; vazio = nenhum script de terceiros.
